# Спортивный клуб — информационная система учёта занятий и посещаемости

Курсовой проект по дисциплине «Разработка программных модулей» (вариант 10).
Django 4.2 LTS – 5.2 + SQLite (Python 3.9+).

## Возможности
- Авторизация по логину и паролю (логины хранятся в таблице БД), две роли: **администратор** и **оператор**.
- Администратор добавляет операторов и ведёт справочники (секции, тренеры, залы, группы). Оператор ведёт клиентов, записи на занятия, посещения и абонементы.
- Клиенты, запись в одну или несколько секций, расписание групп, регистрация посещений, расчёт стоимости занятий со скидкой по абонементу (3–10 %).
- Триггеры БД: длительность занятия по умолчанию 60 мин; не более 10 человек в группе.
- Запросы: список групп с числом клиентов на сегодня; число клиентов-мужчин и клиентов-женщин по видам занятий.
- Выходной документ: расписание зала по дням недели (печать).

## Запуск
```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo      # admin_club/admin12345, operator/operator12345
python manage.py runserver
```

## Тесты
```bash
python manage.py test
```
